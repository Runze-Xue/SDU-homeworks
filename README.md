# SDU Homeworks

山东大学本科阶段可供学习借鉴的课程作业、实验报告、课程项目源码、个人复习笔记和项目成果。

本仓库本次整理包含 **793 个文件，0.74 GiB**。目录按学期和课程保留，Word 文档以 PDF 形式归档以减少隐藏修订和批注。

- `*.cpp`, `*.c`, `*.h`, `*.py`, `*.m` 等：课程实验和作业源码
- `*.pdf`：作业、实验、课程项目报告和复习笔记
- `*.pptx`：本人课程项目展示材料
- `docs/文件清单.jsonl`：上传文件、来源路径和 SHA-256 校验值
