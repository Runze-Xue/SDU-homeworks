# 整理与隐私说明

本仓库面向公开学习交流，筛选目标是让其他学生参考解题思路、实验组织方式、报告结构和项目实现。

## 纳入范围

- 本人署名的课程作业、实验报告和课程项目成果。
- 课程实验源码、可运行的小型样例和结果图。
- 本人复习笔记、知识总结和学习记录。
- 少量本人课程项目展示 PPT。

## 排除范围

- 含个人邮箱、电话、银行卡/银行账号、密码、订阅链接、住址或其他凭据的文件。
- 班级名单、考勤、分班、报名、准考证、行政审批、奖学金和党团务材料。
- 教师课件、教材、试卷题库、参考答案和通用模板。
- 第三方开源项目、模型、数据集、运行环境和编译产物。
- 含组员联系方式的团队展示材料。
