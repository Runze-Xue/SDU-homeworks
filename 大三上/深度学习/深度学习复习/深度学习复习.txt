强化学习难点： Reward delay；Agent要学会去探索世界
强化学习方法分成两块：policy-based 方法(学一个 actor)和 value-based 方法(学一个critic)。
neural network 做 actor的好处：1、穷举所有样例是不现实的，而neural network可以举一反三，比较generalized，可以处理没见过的信息。
怎么看一个actor的好坏？计算 total reward的期望值，好的actor的期望值比较大。

因为训练一个network的泛化能力更强

学习一个价值函数，根据价值函数来推导出策略。

基于价值的算法更新策略的方式通常是贪婪策略或者 ε-贪婪策略

（1）生成式对抗网络的判别器、生成器是什么？
生成器：generator输入一个从如正态分布向量中采样的随机数组成的向量，输出一个训练数据类型的数据，如图片
判别器 Discriminator：输入一个如图片的训练数据，输出一个与二次元人物相似值，表示是真实数据的可能性
（2）训练是怎么进行的？
	首先给generator 和 discriminator 随机初始化
	固定generator，然后给generator输入向量，得到输出图片。用实际图片和generator输出图片作为discriminator的输入，让discriminator做二分类。
	然后固定住discriminator，训练generator，用generator的输出作为discriminator的输入，从discriminator中得到评分，调整generator，让该评分越大越好。
	重复上面对discriminator分类的训练以及generator最大化评分的训练。

7、RNN（有计算）
（1）RNN会有梯度消失和梯度爆炸的情况，分析原因
	梯度消失：累乘导致激活函数导数的累乘，如果取tanh或者sigmoid函数作为激活函数，必然是一堆小数在做乘法，结果就是越乘越小，随着时间序列不断深入，小数的累乘会导致梯度越来越小甚至接近0.
	现象源自过深的网络结构造成网络权重不稳定，本质上来讲是因为梯度反向传播中的连乘效应。
	梯度爆炸：error surface可能变化非常陡峭的，可能前一步计算的梯度比较平坦，下一步到了陡峭处，导致梯度爆炸
解决上述问题的技巧：
使用LSTM 作为模型，可以解决gradient vanishing的问题，但是不能解决梯度爆炸。
为什么LSTM 可以解决gradient vanishing的问题？
因为 memory 和 输入是相加的关系而不是相乘的关系，除非forget gate 关闭，否则memory会一直影响input。
怎样解决梯度爆炸问题？ 对梯度进行clip，如果梯度大于 x，则最大取 x。

（2）lstm神经元和内部的结构，每个门控的作用	
	lstm共有5个激活函数，其中3个是门控激活函数（函数相同），1个输入激活函数，1个cell细胞计算后要通过激活函数，激活函数常用sigmoid。
	c' = g(z)*f(zi) + c * f(zf)
	a = f(zo) * h(c')，a是最终输出
	memory cell 的四个输入是四个标量，来源于同一个向量输入经过线性层变换。

Weight Initialization 权重初始化
1、如果全部初始化为0会怎么样？
权重初始化全为0，那么隐藏层各个神经元的结果都是一样的，从而正向传播的结果是一样的，反向传播求得的梯度也是一样的，所有神经元都在计算同一特征，所以神经网络就失去了特征学习的能力。
2、如果全部随机初始化为小值

（4）初始化为相同的数值有什么问题
权重初始化全为相同值，那么隐藏层各个神经元的结果都是一样的，从而正向传播的结果是一样的，反向传播求得的梯度也是一样的，所有神经元都在计算同一特征，所以神经网络就失去了特征学习的能力。
（5）随机梯度下降，adagrad，adam的原理是什么
随机梯度下降：基于梯度下降，不过每次只选择一个样本进行梯度计算并用于参数更新
adagrad（adaptive gradient algorithm）为每个参数维护一个独立的学习率，并根据该参数的历史梯度信息来调整学习率，对于梯度较大的参数，其学习率会逐渐减小；对于梯度较小的参数，学习率会相对较大。
Adam（adaptive moment estimation）结合了adagrad 的优点，不仅维护了每个参数的自适应学习率，还引入了动量，考虑历史梯度信息。
（6）动量是什么？引入了什么变量，引入原因是什么，公式是什么？
动量可以帮助优化器冲出局部最小值，并更快地找到全局最小值
引入了速度v 和动量因子μ
速度v存储了之前所有梯度信息的累积，动量因子μ控制着之前梯度对当前速度的影响程度
引入原因：传统梯度学习算法的收敛速度慢，容易陷入局部最小值，并且对噪声敏感
有cos，linear等改变学习率的方法

10、神经网络基础
（1）图像分类的定义是什么
图像分类旨在根据图像的内容将其分配到预定义的类别中。使用神经网络进行图像分类，就是使用图片和标签的数据集，使用机器学习算法训练一个分类器。

数据方面，增加更多的数据，使用几何变换、添加噪声等对数据进行增强；
模型方面，选择合适的模型架构，增加神经网络深度，使用在大规模数据集上训练的预训练模型，再根据目标任务进行微调，通过迁移学习提高模型性能
训练方面：选择如SGD，Adam等合适的优化器；选择合适的学习率；使用L1,L2正则化技术防止过拟合；使用Drop-out防止过拟合。添加Batch Normalization层加速模型训练并提高稳定性，使用Early Stop 防止过拟合。

k最近邻法 k应该怎么取？最好的距离计算公式怎么取？
方法1：选择在数据集上表现最好的k和距离公式
方法2：将数据集划分为训练集和 测试集，选择在测试集上表现最好的k和距离公式
方法3：将数据集分为训练集，验证集和测试集，在验证集上选超参数，在测试集上做测试。
方法4：交叉验证，将数据集分成多个folds以及一个固定的test，在多个folds中逐个选做验证集，在test上测试

（5）常见的激活函数Relu，，Leaky rule，tanh，sigmoid之间的对比。（公式简单记一下）
常见激活函数：
sigmoid = 1/ (1+e^-x)

tanh = ( e^x - e^-x )/( e^x + e^-x )
缺点：饱和时同样会造成梯度消失 
ReLU = max(0, x)。ReLU is good default choise for most networks
缺点：不是以0为均值的
Leaky ReLU = max(0.1x, x)
Maxout = max(w1x +b1, w2x +b2)
缺点：造成神经元数目增加
ELU = if x >= 0  then x else a(e^x - 1)
缺点：需要计算指数
